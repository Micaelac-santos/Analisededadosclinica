# Analisededadosclinica
Projeto acadêmico de análise e visualização de dados de uma clínica. 

O projeto tem como objetivo desenvolver uma solução de análise de dados para uma clínica de otorrinolaringologia, utilizando dados fictícios de atendimentos realizados ao longo de 2025. Os dados serão tratados e organizados utilizando Python e Pandas e, posteriormente, utilizados no Power BI para criação de análises e visualizações que auxiliem na compreensão dos atendimentos, cirurgias, convênios e faturamento da clínica.

Planejamento de funcionalidades:

AC1- Tratamento e preparação dos dados: leitura da base XLSX utilizando Python/Pandas, remoção de duplicidades, padronização dos convênios e tratamento da coluna datas.
